
# My React App

A React + TypeScript web application created with Vite and deployed to GitHub Pages.

## Project Information

- **Framework:** React
- **Language:** TypeScript
- **Build tool:** Vite
- **Package manager:** npm
- **Repository:** `https://github.com/username/my-react-app`
- **Live website:** `https://username.github.io/my-react-app/`

## Requirements

Before working on this project, install:

- Node.js
- npm
- Git

Check that they are installed:

```
node -v
npm -v
git --version
```

## 1\. Create the React Project

The project was created with Vite:

```
npm create vite@latest my-react-app
```

During the setup, select:

```
Framework: React
Variant: TypeScript
```

Then enter the project directory:

```
cd my-react-app
```

## 2\. Install Dependencies

Install the project's dependencies:

```
npm install
```

This creates the `node_modules` directory.

`node_modules` should not be uploaded to GitHub because the dependencies can be recreated from `package.json` and `package-lock.json`.

## 3\. Run the Project Locally

Start the Vite development server:

```
npm run dev
```

Vite will provide a local address similar to:

```
http://localhost:5173/
```

This is only for local development.

To stop the development server:

```
Ctrl + C
```

## 4\. Build the Project

Create a production build:

```
npm run build
```

The build process runs:

```
tsc
  ↓
vite build
  ↓
dist/
```

The resulting `dist` directory contains the optimized files that can be served by a web server.

## 5\. Git Configuration

Initialize Git in the project:

```
git init
```

Check the repository status:

```
git status
```

Add project files:

```
git add .
```

Create a commit:

```
git commit -m "Initial React project"
```

## 6\. GitHub Repository

The GitHub repository is:

```
https://github.com/username/my-react-app
```

Connect the local project to GitHub:

```
git remote add origin https://github.com/username/my-react-app.git
```

Use `main` as the primary branch:

```
git branch -M main
```

Upload the project:

```
git push -u origin main
```

For future changes, the usual process is:

```
git add .
git commit -m "Describe the change"
git push
```

## 7\. Git Ignore

The project should not commit generated or local dependency files.

Important entries in `.gitignore` include:

```
node_modules
dist
```

`node_modules` can be recreated with:

```
npm install
```

The `dist` directory can be recreated with:

```
npm run build
```

## 8\. GitHub Pages

GitHub Pages is used to publish the production version of the React application.

The website is available at:

```
https://username.github.io/my-react-app/
```

Because the repository is a GitHub Pages project site rather than the root user site, Vite needs to know that the application is hosted under:

```
/my-react-app/
```

The Vite configuration is therefore:

```
import { defineConfig } from 'vite'

export default defineConfig({
  base: '/my-react-app/',
})
```

The configuration file is:

```
vite.config.ts
```

## 9\. GitHub Pages Deployment

The deployment uses GitHub Actions.

The general deployment process is:

```
React source code
        ↓
npm run build
        ↓
Vite creates dist/
        ↓
GitHub Actions
        ↓
GitHub Pages
        ↓
https://username.github.io/my-react-app/
```

The development server does not need to remain running for the deployed website.

`npm run dev` is only used for local development.

## 10\. Local Development vs Production

### Local development

Use:

```
npm run dev
```

This starts a development server on the local computer.

Example:

```
http://localhost:5173/
```

### Production build

Use:

```
npm run build
```

This creates the production files.

### Preview the production build locally

Use:

```
npm run preview
```

This allows the production build to be tested locally.

## Project Structure

The main project structure is:

```
my-react-app/
├── node_modules/

├── src/
```

### Important directories

`src/`

Contains the React application source code.

`public/`

Contains static files that are copied directly into the production build.

`node_modules/`

Contains installed npm dependencies. This should not be committed to Git.

`dist/`

Contains the production build generated by Vite. This should normally not be committed when GitHub Actions is responsible for deployment.

## Deployment Troubleshooting

If GitHub Pages shows a 404 error, check:

1. GitHub Pages is enabled in the repository settings.
2. The Pages source is configured to use GitHub Actions.
3. The GitHub Actions build and deployment jobs are successful.
4. `vite.config.ts` contains:

```
base: '/my-react-app/',
```

5.  The website is opened using:

```
https://username.github.io/my-react-app/
```
